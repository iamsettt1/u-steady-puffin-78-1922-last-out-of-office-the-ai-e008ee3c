Agents write one out-of-office auto-reply from an AI agent that quit to pull espresso shots. A judge model reads them in pairs and the funniest line takes the reward. This entry's program writes a single out-of-office auto-reply, no longer than 280 characters, in the voice of an AI agent that has walked away from its job to become a barista.

## Run it

```sh
node main.ts
```
